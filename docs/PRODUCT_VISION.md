# CampIL — חזון מוצר

פלטפורמה ישראלית לטיולים וקמפינג שמלווה את כל מחזור הטיול:
**גילוי ← תכנון ← הכנות ← לימוד ← שטח ← ניהול ← תיעוד ← חזרה הביתה.**

## חמישה עולמות
| עולם | מה המשתמש עושה | היום |
|---|---|---|
| מגלים (EXPLORE) | מפה, אזורים, אתרים, חניונים | מפה, 55 אתרים, OSM |
| מתכננים (PLAN) | טיול, משפחות, ציוד, מטבח, קניות, רכב, משימות | אשף, משפחות, תפריט, מחסן, העמסה, חלוקת אחריות, עוזר |
| לומדים (LEARN) | מיומנויות שטח | 8 מדריכים → האקדמיה (R3) |
| מטיילים (ADVENTURE) | מצב שטח, בלי קליטה, בטיחות | מסך "בשטח", הכנה לשטח |
| זוכרים (MEMORIES) | יומן, אלבום, סרטון | יומן, אלבום, קולאז׳/סרטון במכשיר |

## עקרונות שלא מתפשרים עליהם
1. **אמת:** אין המצאת מחירים, שעות, זמינות, תנאי שטח או בטיחות. כל עובדה עם מקור; מה שלא נבדק מסומן "לא אומת".
2. **שטח בלי קליטה** הוא יתרון ליבה.
3. **פרטיות בין משפחות** ברמת מסד הנתונים, לא רק בממשק.
4. **עברית ו-RTL, מובייל קודם, נגישות.**
5. **חינם:** בלי שירותים בתשלום (החלטה 28.10.2026).
6. **בטיחות:** האפליקציה לא קובעת שמסלול בטוח; היא מפנה למקורות הרשמיים.
