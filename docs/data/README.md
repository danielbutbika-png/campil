# מאגר המקומות של CampIL

## מקורות
| מקור | מה לוקחים | רישיון |
|---|---|---|
| Wikidata | שם בעברית ובאנגלית, מיקום, סוג, אתר רשמי, ערך בוויקיפדיה, הכרזת מורשת | CC0 |
| OpenStreetMap | חניוני לינה ויום, חופים, מפלים, תצפיות, מערות, שבילים, מתקנים כפי שסומנו, שעות לפי OSM | ODbL — עם קרדיט |
| Wikimedia Commons | תמונה אחת למקום, **רק** ברישיון חופשי, עם יוצר ורישיון | לפי התמונה |
| ויקיפדיה (בזמן אמת) | תקציר הערך, מוצג עם קישור | CC BY-SA |
| הקטלוג הידני (`src/data/sites.ts`) | תיאור, קושי, התאמה למשפחות | של CampIL |

**מה לא לוקחים ממקורות פתוחים:** מחירים, הזמנות, סגירות ושעות "רשמיות". אלה מוצגים "לא ידוע", עם קישור לאתר הרשמי.

## צינור העדכון (`scripts/enrich/`)
רץ ב-GitHub Actions (workflow **Data refresh**), רק כשדוחפים את הענף `data-refresh` או מפעילים ידנית. הוא לא מפרסם כלום לאפליקציה.
1. `wikidata.mjs`: שאילתה אחת לכל קטגוריה, בתוך גבולות ישראל, עם User-Agent מזוהה והפסקה בין שאילתות. לכל תמונה נבדק הרישיון ב-Commons.
2. `osm.mjs`: מקומות עם שם בעברית מ-Overpass, שאילתה אחת לכל קטגוריה עם הפסקה של 8 שניות. מתקנים נשמרים רק כפי שסומנו, בלי השלמות.
3. `merge.mjs`: שלבי האיחוד:
   - שיוך לאזור לפי הפוליגונים של האפליקציה.
   - איחוד כפולים: אותו מזהה Wikidata, או אותו שם במרחק של עד 1 ק״מ.
   - קישור לקטלוג הידני.
   - דוח מיזוג.
4. `coverage.mjs`: דוח כיסוי לפי 30 הקטגוריות והאזורים.

התוצאות נשמרות בענף `ci-reports` תחת `data/`. אחרי בדיקה, `places.json` מועתק ל-`public/data/places.json`.

## בקרת איכות
- מקום מחוץ לאזורי האפליקציה, או בלי שם בעברית, לא נכלל.
- נחלים, פסגות, אתרים ארכיאולוגיים ופארקים נכללים רק אם יש להם ערך בוויקיפדיה, תמונה או אתר רשמי.
- כמה מקומות באותו שם (שמורה מול אתר עתיק) נשארים נפרדים. האפליקציה מציגה את כולם עם האזור והסוג, והמשתמש בוחר.
- כל מקום שומר את מזהי המקור שלו (`qid`, `osm`), כך שאפשר לבדוק מחדש כל נתון.
