# תסריט בדיקות במכשירים אמיתיים (MOB-001)

**סטטוס: ממתין לבדיקה.** אף שורה כאן לא נבדקה במכשיר פיזי על ידי Claude — אין לו גישה לטלפונים. הבדיקות האוטומטיות רצות ב-Chromium מדומה בגודל טלפון (390×844) ואינן תחליף.
מבצע: אדם עם אייפון אחד (Safari + אפליקציה מותקנת למסך הבית) ומכשיר Android אחד (Chrome + התקנה). לחלק מהתרחישים צריך טלפון שני (שותף).
זמן משוער: 45–60 דקות לכל מכשיר. כתובת: https://danielbutbika-png.github.io/campil/staging/ (סביבת בדיקות, נתונים נפרדים).
