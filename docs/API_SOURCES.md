## נתונים שהאפליקציה **לא** מציגה, ולמה
מחירים, שעות פתיחה, זמינות, דירוגים, מצב שבילים וסגירות — אין מקור פתוח ומעודכן. במקומם: קישור למפעיל, ושדה "הבדיקה שלכם" עם תאריך.
